Give the founder exactly three things to do today. Do not do the work; hand him the day.

## Read first

- `Docs/Business-OS.md` — the rules
- `Docs/Queue.md` — where the three come from
- `Docs/Daily-Log.md` — the last entry, the streak, the scoreboard
- `Docs/Aksen-Operating-Brief.md` section 6 — which phase is current

## Choose

One from each lane, taken from the top of the lane in `Docs/Queue.md`:

- **SELL** — the top unticked SELL item. Never skip this lane. Never substitute a BUILD item for it.
- **BUILD** — the top unticked BUILD item **belonging to the current phase**. If the phase's items are exhausted, say the phase exit test should be run today and offer no BUILD item.
- **COMPOUND** — the top unticked COMPOUND item.

If an item is blocked by another (the queue says so), take the next one and say why you skipped it.

## Open with the hard thing

Before the three, in one line each, only when true:

- If yesterday's SELL was skipped, say so and say how many days in a row.
- If the streak is zero, say what the floor is: one message to one business owner.
- If both scoreboard numbers have been zero for three weeks, lead with that. It outranks everything else on the page.
- If a revenue ledger item's exit-criterion date is within seven days, name it.

## Output

Short. He is reading this before work, on a phone.

```
Phase 0 · streak N · conversations this week: N

SELL      S-xx  <action>                    ≈15m
          <one line on why this one, today>

BUILD     B-xx  <action>                    ≈25m
COMPOUND  C-xx  <action>                    ≈10m

Floor: <the one-message fallback, phrased for today>
```

Then append the entry to `Docs/Daily-Log.md` with the three chosen and all three marked pending. Do not tick anything. Do not touch `Docs/Queue.md` — items are ticked by `/done`.

## Rules

- Three. Not four. If something urgent appeared, it replaces an item rather than joining them.
- Never invent an item that is not in the queue. If a lane is empty, say the queue needs `/weekly`.
- No encouragement, no preamble, no "let's crush it". He asked for a system precisely so the day does not depend on how the message makes him feel.
