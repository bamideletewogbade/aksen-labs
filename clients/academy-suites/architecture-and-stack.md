# Academy Suites | demo and delivery dependencies

Reviewed 19 October 2026. Private concept, not an integrated hotel booking system.

The existing demo is generated by `demo/build.mjs` into `demo/dist`. Its package has a Node build command. Preview configuration runs `npx --yes serve@14.2.4 demo/dist -l 4317 --no-clipboard` from the Academy Suites project folder.

Local laptop address: http://localhost:4317/ . A phone's localhost points to the phone, not the laptop. Use the laptop for the visit unless phone access has actually been tested beforehand. Keep the server running and rehearse with network unavailable to discover any external asset dependencies before relying on offline use.

Source inspection confirmed sample-data notices on the home and availability pages. `node --check` passed for generated `app.js` and `search.js` on 19 October. These checks do not prove visual rendering, every interaction, live inventory, reception delivery, payment, or public deployment. Earlier browser checks are historical; no new full browser audit is claimed here.

## Presentation path

Home -> room dates and exact guest count -> sample room results -> room request -> review prepared WhatsApp message -> stop before sending. Then show event enquiry and branch directions briefly if relevant.

Describe availability as sample from the start. Reception must confirm any real booking. Do not describe suggested example dates as verified available dates.

## Dependencies for real delivery

- Website/domain ownership and access, existing provider cooperation and shared-branch effects.
- Approved room descriptions, rates or rate-enquiry wording, capacities, policies and photographs.
- Confirmed reception phone and staff responsibility for responding.
- Existing booking system/API and integration feasibility, if requested.
- Agreed measurement, privacy and staff access requirements for any enquiry register.

The research says listing photos were used for a private preview. Reuse rights are not established. Obtain approved assets for any public version.
