## Portfolio Standards

Every client engagement directory in this folder maintains:
1. `README.md`: Engagement overview, commercial status, and tech summary.
2. `discovery-and-strategy.md`: Business model, market gaps, competitor read, and target persona.
3. `services-and-pricing.md`: Phased scopes, transparent milestone payments, and comparative agency benchmarks.
4. `architecture-and-stack.md`: Technical topologies, database rationale, and API integrations.
5. `current-status.md`: Real-time milestone tracker, deployment status, and upcoming deliverables.
